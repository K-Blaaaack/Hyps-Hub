## 4. 已知限制 / 后续

1. **未做真实合成器下的窗口行为验证**：截图使用 `offscreen`；Wayland 缩放、分数 DPI、输入法候选框位置仍建议在 niri/GNOME 上人工过一遍。
2. **未做 GUI 点击自动化**：键盘焦点框、对话框默认焦点、Toast 位置通过代码与静态截图复核，没有 xdotool/Qt Quick Test 级的点击回归；本次未引入 UI 测试框架。
3. **滚动条按需显示**：页面统一 `AsNeeded`，滚轮/触控板可用，但鼠标用户首次看到「内容被切在底边」时可能不知道可以滚动；若后续做用户测试，可考虑在长页面加 8px 常显轨道或底部渐隐。
4. **未做完整 WCAG 审计**：已补自定义控件名称/角色/焦点与主要对比度，但字体缩放、200% 文本、屏幕阅读器逐控件走查未执行。
5. **列表半行**：任务/最近任务列表在底部仍可能露出半行（可滚动列表的正常表现）；已通过行高与滚动条降低突兀感，未做渐隐遮罩。
6. **未改动视觉资产**：Logo、噪点/警戒线纹理、图标均为原有资产，未重新生成。
